# Temp Mail

**Live site: https://tempmaill.tech**

Free temporary disposable email service. Get an instant throwaway email address — no signup, no personal data. Emails auto-delete after 1 hour.

## Features

- ⚡ Instant temporary email inbox, no registration
- 🔒 Privacy-first: nothing stored, auto-deletion
- 📧 Multiple domains (abahi.tech, abahi.page, abahi.me)
- 📝 Email privacy guides on the [blog](https://tempmaill.tech/blog)
- 🛠️ Admin panel for managing articles

## Tech stack

- Next.js 16 + React 19 + Tailwind CSS
- Cloudflare Email Routing + Workers + KV for mail handling
- Deployed on Vercel

## Use cases

Verification codes, trial signups, spam avoidance, and keeping your real inbox clean.
